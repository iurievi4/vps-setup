## 📖 Описание

Коллекция готовых HTML-шаблонов для создания современных сайтов-заглушек.

Шаблоны предназначены для использования в составе VPS-инфраструктуры, тестовых окружениях, демонстрациях и прототипах.

Коллекция включает различные типы интерфейсов: страницы ошибок, игровые сайты, конвертеры, файловые сервисы, видеохостинги и другие варианты.

> ⚠️ **Важно:** представленные страницы являются статическими HTML-шаблонами и демонстрационными интерфейсами. Они не являются настоящими сервисами и не предоставляют соответствующую функциональность реальных платформ.

## 🚀 Быстрый старт

### Клонирование репозитория

```bash
git clone https://github.com/iurievi4/vps-setup.git
cd vps-setup
```

### Расположение шаблонов

Шаблоны находятся в каталоге:

```text
nginx/templates/
```

Структура:

```text
nginx/
└── templates/
    ├── 503 error pages/
    ├── Cloud storage/
    ├── Download manager/
    ├── File converter/
    ├── Games site/
    ├── Memes site/
    ├── Mod manager/
    ├── Speed test/
    ├── Video converter/
    └── Video hosting/
```

### Использование шаблона

Выберите нужный шаблон и скопируйте его содержимое в корневой каталог вашего Nginx-сайта.

Например:

```bash
mkdir -p /var/www/html
cp -r "nginx/templates/503 error pages/v1/." /var/www/html/
```

После копирования проверьте конфигурацию Nginx:

```bash
nginx -t
```

Если проверка прошла успешно:

```bash
systemctl reload nginx
```

> 💡 Если используется отдельный виртуальный хост Nginx с другим `root`, необходимо копировать файлы именно в каталог, указанный в конфигурации этого сайта.
