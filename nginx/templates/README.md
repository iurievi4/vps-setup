## 📖 Описание

Коллекция готовых HTML-шаблонов для Nginx, предназначенных для создания тестовых веб-страниц, демонстрационных сайтов и страниц-заглушек.

Шаблоны включают HTML, CSS, JavaScript, изображения и другие необходимые статические ресурсы.

Коллекция интегрирована в репозиторий:

**`iurievi4/vps-setup`**

и может использоваться совместно со скриптом управления Nginx-шаблонами.

> ⚠️ **Важно:** шаблоны являются статическими демонстрационными материалами. Они не являются полноценными веб-сервисами и не должны использоваться для имитации или выдачи себя за реальные сторонние сервисы.

## ✨ Особенности

- 🤖 **AI-Generated** — часть шаблонов создана с использованием современных AI-инструментов
- 🎯 **Готовые страницы** — можно быстро развернуть на Nginx
- 📱 **Адаптивность** — поддержка мобильных устройств
- ⚡ **Минимальные зависимости** — преимущественно статический HTML/CSS/JS
- 🛠️ **Простая установка** — достаточно скопировать содержимое выбранного шаблона
- 🎨 **Современный дизайн** — различные стили и варианты интерфейсов
